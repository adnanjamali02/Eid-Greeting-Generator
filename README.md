## 📸 Preview

> An immersive, dark-themed Islamic aesthetic with animated starfields, geometric patterns, golden crescent moon, and ornate greeting cards that feel premium and handcrafted.

The generator features an elegant dark emerald-and-gold UI, a live card preview, and eight distinct greeting styles rendered in a decorative framed card — all instantly downloadable as a PNG image.

---

## ✨ Features

| Feature | Details |
|---|---|
| 🎨 **8 Greeting Styles** | Formal, Warm, Family, Professional, Poetic, Short & Sweet, Youth/Gen-Z, Dua & Prayer |
| 🌍 **3 Languages** | English 🇬🇧 · Urdu 🇵🇰 · Arabic 🕌 |
| 🎭 **6 Card Themes** | Emerald, Midnight, Crimson, Desert, Celestial, Regal |
| 📥 **Download PNG** | High-resolution 2× card download via html2canvas |
| 📋 **Copy to Clipboard** | One-click full text copy |
| 💬 **WhatsApp Share** | Direct WhatsApp share link with formatted message |
| ✍️ **Personalised Names** | Recipient & sender name fields |
| ✨ **Animated UI** | Starfield background, floating crescent, shimmer effects |
| 📱 **Fully Responsive** | Mobile, tablet & desktop |
| 🚫 **Zero Dependencies** | Single HTML file — no npm, no build step |

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, animations, grid/flexbox, backdrop-filter
- **Vanilla JavaScript** — ES6+ (no frameworks)
- **Google Fonts** — Cinzel Decorative, EB Garamond, Amiri, Noto Nastaliq Urdu
- **html2canvas 1.4.1** — PNG card download (CDN, no install needed)
- **GitHub Pages** — Free hosting & deployment

## 🚀 Quick Start

### Option 1 — Open directly (easiest)

```bash
# Clone the repo
git clone https://github.com/adnanjamali02/eid-greeting-generator.git

# Open in your browser
open eid-greeting-generator/index.html
```

No server required. Just open `index.html` in any modern browser.

### Option 2 — GitHub Pages (recommended for sharing)

1. Fork this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site is live at `https://yourusername.github.io/eid-greeting-generator`

### Option 3 — Live Server (for development)

```bash
# Using VS Code Live Server extension, or:
npx serve .
```

## 🎯 How to Use

1. **Enter the recipient's name** (e.g. *Ammi*, *Ali Bhai*, *Sarah*)
2. **Enter your name** as the sender
3. **Select a language** — English, Urdu, or Arabic
4. **Choose a greeting style** from the 8 style cards
5. **Pick a card theme** (colour scheme)
6. **Click "Generate My Eid Card"**
7. **Download** the card as PNG, **Copy** the text, or **Share on WhatsApp**
